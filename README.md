# 가구 배치 시뮬레이터

집의 가구 배치를 실제로 옮기지 않고 가상으로 시험해 보는 정적 웹앱입니다. 2D 평면도와 3D 뷰가 같은 데이터를 보여 주므로, 어느 쪽에서 옮겨도 양쪽에 바로 반영됩니다. 서버 없이 브라우저에서만 동작하며 GitHub Pages로 배포합니다.

## 실행

```bash
npm install
npm run dev       # http://localhost:5173/layout-please/
npm test          # 단위 테스트 (Vitest)
npm run build     # dist/ 에 정적 파일 생성
npm run preview   # 빌드 결과 확인 (http://localhost:4173/layout-please/)
```

## 기능

**배치 모드 (기본)**
- 왼쪽 목록에서 가구 추가: 클릭하면 화면 가운데에, 평면도로 끌어다 놓으면 그 자리에 놓입니다.
- 가구 이동은 드래그, 회전은 90° 버튼(R / Shift+R) 또는 각도 입력.
- 벽·가구·그리드 스냅. 툴바에서 각각 켜고 끄고, 그리드 간격을 고릅니다. Alt를 누른 채 끌면 잠시 스냅이 꺼집니다.
- 오른쪽 패널에서 이름, 형태, 가로·세로·높이, 위치, 회전, 색을 숫자로 정밀 편집합니다.
- 박스 가구 만들기, 내 프리셋으로 저장.
- 되돌리기/다시 실행(Ctrl+Z / Ctrl+Y), 복제(Ctrl+D), 삭제(Delete), 방향키로 이동(Shift는 1cm).
- 선택한 가구의 크기와 네 방향 벽까지 거리를 표시합니다.

**구조 편집 모드 (PC)**
- 방을 클릭해 꼭짓점을 끌거나 cm 단위로 입력합니다. 변 가운데 ⊕로 꼭짓점을 추가합니다.
- 방 모양을 바꾸면 그 방 둘레의 벽이 자동으로 따라옵니다. 벽 두께는 유지되고 문·창은 가장 가까운 새 벽으로 옮겨 붙습니다.
- 벽(끝점, 길이, 두께), 문(여닫이/미닫이/접이/개구부, 위치, 폭, 경첩, 여는 쪽), 창(위치, 폭, 창턱, 높이), 붙박이 설비, 천장 높이를 편집합니다.

**충돌 검사**: 배치를 막지 않고 경고만 합니다.
- 방 밖으로 나감, 벽과 겹침(문 자리는 제외), 가구·설비끼리 겹침(회전된 사각형 SAT 판정).
- 문 영역 침범: 여닫이·접이문은 문이 열리는 부채꼴, 미닫이·개구부는 문 앞뒤 30cm 통로.
- 문제가 있는 가구는 2D와 3D에서 빨간색으로 표시됩니다. 툴바의 "확인 필요" 배지를 누르면 문제 가구를 차례로 선택합니다.

**3D 뷰**
- 궤도 카메라: 마우스 드래그로 회전, 휠로 줌, 오른쪽 드래그로 팬. 터치는 한 손가락 회전, 두 손가락 줌·팬.
- 가구 선택과 바닥 드래그 이동(스냅 포함).
- 벽 표시: 자동(카메라와 방 사이 벽 반투명), 불투명, 낮게. "위에서" 보기와 시점 초기화.

**저장과 공유**
- 브라우저(localStorage)에 자동 저장됩니다. 집 구조, 모든 배치안, 내 프리셋, 화면 설정이 대상입니다.
- 배치안(A안/B안…) 전환·복제·이름 변경·추가·삭제로 여러 안을 비교합니다.
- 파일 메뉴: JSON 내보내기/불러오기, 공유 링크 만들기, 샘플로 초기화.
- 공유 링크: 집 구조와 현재 배치안을 압축해 URL 해시(`#s=…`)에 담습니다. 서버에 올라가지 않습니다. 링크를 열면 열람 모드로 보이고, "내 저장소로 가져오기"를 누르면 저장됩니다. 같은 집이면 배치안만 추가되고, 다른 집이면 기존 데이터를 JSON으로 백업한 뒤 교체합니다. 링크가 2,000자를 넘으면 경고합니다.

**모바일 (열람 위주)**
- 768px 이하에서는 패널을 숨기고 2D/3D를 탭으로 전환합니다.
- 한 손가락 이동, 핀치 줌, 가구 끌기, 아래 막대로 회전·복제·삭제를 할 수 있습니다. 구조 편집과 정밀 입력은 PC 전용입니다.

## 기술 선택

- Vite + TypeScript + Preact(UI 패널) + three.js(3D, 기본 도형 조합만 사용, 외부 모델 파일 없음) + lz-string(공유 링크)
- **2D는 SVG를 썼습니다.** 요소마다 클릭 판정과 이벤트를 바로 받을 수 있고 치수선·글자를 그리기 쉬우며, 팬/줌은 viewBox만 바꾸면 되기 때문입니다.
- 상태: 자체 store(`src/store`)와 스냅샷 Undo/Redo. 뷰(2D, 3D, 패널)는 store를 구독하고 `actions`만 호출하므로 데이터 모델과 뷰가 분리됩니다.
- three.js는 3D 뷰를 처음 열 때 불러옵니다(지연 로딩). 첫 화면 JS는 약 34kB(gzip)입니다.
- 충돌 검사는 가구 객체 단위로 결과를 캐시합니다. 드래그 중에는 움직인 가구만 다시 계산합니다.

## 데이터 모델

모든 길이는 cm입니다. 평면도 좌표는 x가 오른쪽, y가 아래이고, 회전은 시계방향(도)입니다. 정의는 [`src/model/types.ts`](src/model/types.ts)에 있습니다.

- `House`: 천장 높이, 방(`Room`, 실내 면 기준 다각형), 벽(`Wall`, 중심선 + 두께, 자동 생성 벽은 `roomId`), 문(`Door`), 창(`HouseWindow`), 붙박이 설비(`Fixture`)
- `Furniture`: 형태(`shape`), 가로·세로·높이, 색, 중심 위치, 회전. 정면은 로컬 +y 방향입니다.
- `Layout`: 가구 목록 한 세트(배치안)
- `ProjectDoc`: `version`, 집, 배치안들, 활성 배치안, 사용자 프리셋. 저장·불러오기·공유 링크는 모두 [`src/model/migrate.ts`](src/model/migrate.ts)를 거쳐 현재 버전으로 올라옵니다.

스키마를 바꿀 때는 `SCHEMA_VERSION`을 올리고 `MIGRATIONS`에 `이전 버전 → 다음 버전` 변환 함수를 추가합니다. 공유 링크의 압축 형식은 [`src/logic/share.ts`](src/logic/share.ts)의 `FORMAT`으로 따로 관리합니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `src/model` | 데이터 타입, 프리셋, 샘플 집, 문서/구조 조작 순수 함수, 마이그레이션 |
| `src/geometry` | 벡터, 회전 사각형, 다각형, SAT, 선분·반직선 (순수 함수) |
| `src/logic` | 충돌 검사, 스냅, 벽 자동 생성, 문/창 위치, 거리 측정, 직렬화, 공유 링크 (순수 함수) |
| `src/store` | store, Undo 기록, 액션, 셀렉터, 자동 저장 |
| `src/view2d` | SVG 평면도 |
| `src/view3d` | three.js 장면, 가구·집 3D 형태 |
| `src/ui` | 툴바, 패널, 파일 메뉴, 모바일 막대 |

순수 로직(`model`, `geometry`, `logic`, `store`)에는 같은 폴더에 `*.test.ts` 단위 테스트가 있습니다.

## 배포 (GitHub Pages)

1. GitHub에 저장소를 만듭니다. 이름은 `layout-please`를 권장하며, 다른 이름도 됩니다.
   - 무료 계정에서 Pages를 쓰려면 **공개 저장소**여야 합니다. 샘플 데이터(집 평면)도 공개된다는 점에 유의하세요.
2. 이 폴더를 저장소에 푸시합니다.
   ```bash
   git remote add origin https://github.com/<사용자>/layout-please.git
   git push -u origin main
   ```
3. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
4. `main`에 푸시할 때마다 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)이 테스트 → 빌드 → 배포를 실행합니다. Actions 탭에서 진행 상황을 볼 수 있습니다. 완료되면 `https://<사용자>.github.io/<저장소>/`에서 열립니다.

`vite.config.ts`의 `base`는 기본값이 `/layout-please/`입니다. 배포 워크플로는 `BASE_PATH`를 저장소 이름으로 자동 설정하므로, 저장소 이름이 달라도 따로 고칠 필요가 없습니다.
